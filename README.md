# 🎬 Movie API Telegram Bot (movie_api_bot)

Telegram-бот для поиска фильмов и сериалов с интеграцией внешнего REST API и локальной базой данных для ведения истории запросов. Проект разработан в рамках портфолио для демонстрации навыков работы с API, СУБД и построения логики серверных приложений на Python.

---

## 📌 Описание проекта и ТЗ

Бот взаимодействует с внешним REST API Кинопоиска (через кастомный клиент) и предоставляет пользователю гибкий интерфейс для поиска кинолент по различным критериям. Вся история запросов логируется на стороне бота в локальной БД.

### ⚙️ Реализованный функционал (Команды):
* `/movie_search` — быстрый поиск фильма или сериала по его названию.
* `/movie_by_rating` — поиск кино с фильтрацией по рейтингу Кинопоиска (от высоких к низким).
* `/low_budget_movie` — выборка кинолент с низким бюджетом (до $500,000) для любителей артхауса и инди-индустрии.
* `/high_budget_movie` — поиск высокобюджетных голливудских блокбастеров.
* `/history` — вывод персональной истории поисковых запросов пользователя.

### 📋 Параметры фильтрации при поиске:
Каждая поисковая команда гибко настраивается с помощью передачи аргументов:
1. **Название** (для текстового поиска).
2. **Жанр** (комедия, ужасы, фантастика, драма и т.д.).
3. **Количество выводимых вариантов** (лимитирование выборки).

---

## 📊 Структура вывода данных

Бот гарантирует полноту информации и для каждого найденного фильма (а также в истории запросов) парсит из API и отображает следующие UI-элементы:
* 🖼️ **Постер** фильма
* 🎥 **Название** и **Год производства**
* ⭐️ **Рейтинг** (Кинопоиск / IMDb)
* 🎭 **Жанр(ы)**
* 🔞 **Возрастной рейтинг** (MPAA / возрастное ограничение)
* 📝 **Описание** (краткий синопсис)
